# DealSense API

AI-powered sales meeting outcome predictor.

## Endpoints
- `POST /predict` — Upload audio file, get deal prediction
- `POST /transcribe` — Upload audio, get transcript
- `POST /predict-text` — Paste transcript text, get deal prediction
